# Known gaps and traps

Things in the **current mod version (9.9.0)** that look like they should work based on folder names, in-game text, or their own naming, but do not — or that behave differently from what their name suggests. Every entry below is checked directly against the mod's own source, not guessed. This page is about present-day behavior, not about updating between versions; for that, see [Migrations](migrations.md).

Nothing outstanding as of this version — both entries that used to be here (`PlayerHasOneOfCustomDataKeys`'s float check, `GiveBuff`'s duration argument) were fixed in this release.
